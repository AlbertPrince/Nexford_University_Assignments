# Fashion MNIST Classifier (Python)

This project uses a 6-layer Convolutional Neural Network (CNN) to classify clothing images from the Fashion MNIST dataset.

## Requirements

- Python 3
- TensorFlow
- NumPy
- Matplotlib

## How to Run

1. Install dependencies:
   pip install tensorflow numpy matplotlib

2. Run the Python file:
   python fashion_assignment.py

## Output

The model will train on the dataset and display predictions for 2 images.

## File Details

- `fashion_assignment.py`: The main Python script
